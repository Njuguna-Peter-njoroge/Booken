# Booken - Get Your New Book Collections

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Booken** is a stylish and interactive e-commerce website template designed for book lovers. It provides a visually appealing platform to showcase and sell new book collections, with features like a dynamic header, featured collections, and product filtering.



## Features

- **Dynamic Header:**
    - Fixed header that becomes active (slides in) on scroll.
    - Includes a logo, search bar, cart, user login, and mobile navigation toggle.
    - Mobile navigation with a separate search bar and a list of links.
- **Hero Section:** Engaging banner with a title, description, call-to-action button, and a promotional image.
- **Feature Section:** Highlights key benefits like free shipping, secure payment, best price, and easy return.
- **Featured Collection:** Showcases new book collections with product cards including:
    - "New" badge for new arrivals.
    - Product image with hoverable quick view, wishlist, compare, and add-to-cart actions.
    - Product title and price.
    - Star rating.
- **Offer Section:** Promotes special offers with a subtitle, title, countdown timer, and a call-to-action button.
- **Popular Section:** Allows filtering of popular books by category.
- **Blog Section:** Displays recent blog posts with images, titles, meta information, excerpts, and a call-to-action button.
- **Footer:** Contains brand information, social media links, a list of links, and copyright information.
- **Back to Top Button:** Smoothly scrolls the user back to the top of the page.
- **Responsive Design:** Adapts to different screen sizes for an optimal viewing experience on desktops, tablets, and mobile devices.
- **Interactive Elements:** Includes hover effects, active states, and a mobile navigation toggle.

## Technologies Used

- **HTML:** Provides the semantic structure of the webpage.
- **CSS:** Styles the layout, appearance, and responsiveness of the website. Includes custom properties for easy theme customization.
- **JavaScript:** Adds interactivity such as:
    - Toggling the mobile navigation menu.
    - Adding an "active" class to the header and back-to-top button on scroll.
    - Implementing filtering functionality for the popular books section.
- **Google Fonts:** Uses "Jost" and "Work Sans" for elegant typography.
- **Ionicons:** Provides scalable vector icons for various UI elements.

## Usage

This template provides a solid foundation for your online bookstore. To customize it:

- **Replace Placeholder Content:** Update the text, images, and links throughout the `index.html` file with your own content.
- **Modify Styles:** Edit the `assets/css/style.css` file to change the colors, fonts, spacing, and overall appearance to match your brand.
- **Integrate Backend:** To create a fully functional e-commerce website, you will need to integrate this frontend template with a backend system for managing products, orders, user accounts, and payments.
- **Customize JavaScript:** Modify the `assets/js/script.js` file to add or change the interactive features as needed.

## Customization

Here are some key areas you might want to customize:

- **Branding:** Update the logo in the header and footer (`assets/images/logo.svg`). Modify the primary and secondary colors in the `:root` section of `assets/css/style.css`.
- **Images:** Replace the placeholder book images in the `assets/images/` directory with your own product photos. Update the hero banner and blog post images.
- **Text Content:** Modify all the text content in `index.html` to reflect your bookstore's information, product descriptions, blog posts, etc.
- **Links:** Update all the `href` attributes in the `<a>` tags to point to your actual website pages, product details, blog posts, and social media profiles.
- **Offer Countdown:** Adjust the dates and times in the JavaScript (if implemented) for the offer countdown timer.
